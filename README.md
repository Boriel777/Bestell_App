# 🍽️ Dali's Bestell App

<em>A dynamic food ordering web app built as part of Developer Academy exercises — focused on JavaScript business logic, dynamic rendering, and shopping cart functionality.</em>

---

## 💡 The Idea

This project was built as a **hands-on exercise** to deepen my JavaScript skills by implementing the business logic behind a food ordering application.

The main focus was on **dynamic content rendering**, **shopping cart logic**, **data management**, and **persistent client-side storage** without using a framework.

- Dynamically generated menu and food categories from JavaScript data
- Interactive shopping cart with quantity management
- Automatic subtotal, delivery fee, and total calculation
- Cart state persistence using `localStorage`
- Responsive navigation with mobile cart modal
- Dynamic UI updates based on the current shopping cart state

---

## ⚡ Key Highlights

- **Data-driven menu** – Menu categories and meals are generated dynamically from JavaScript objects instead of static HTML
- **Shopping cart logic** – Users can add, remove, and adjust the quantity of meals
- **Dynamic calculations** – Subtotal, delivery fee, and total amount update automatically when the cart changes
- **Persistent cart state** – Cart data is stored in `localStorage` and restored after refreshing the page
- **Dynamic CTA states** – Menu buttons reflect whether an item is already in the cart and display the current quantity
- **Reusable templates** – Menu cards, cart items, and summary sections are generated through template functions
- **Responsive cart experience** – Desktop cart layout and mobile cart modal provide different interaction patterns
- **Modular JavaScript structure** – Logic is separated into database, templates, functions, navigation, and storage modules
